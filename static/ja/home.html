プラットフォームの透明性

プラットフォームの透明性データが、
一目瞭然。

EU デジタルサービス法（DSA）の透明性レポートと Google の政府コンテンツ削除要請を対象とする、インタラクティブなダッシュボードと構造化クエリ API。

データを探索 API リファレンス

ここにあるもの

DSA

EU デジタルサービス法（DSA）の透明性レポートに基づくコンテンツモデレーション統計 — 指定された超大規模オンラインプラットフォームに加え、同じ EU 調和テンプレートを提出する数十のプラットフォームが対象です。

グラフを見る & クエリ

NY ToS

ニューヨーク州のソーシャルメディア利用規約報告 — Stop Hiding Hate Act に基づき、プラットフォームが年 2 回 NY 司法長官に提出するポリシー文書。アーカイブ付きのカタログ。

カタログを見る

CA AB 587

カリフォルニア州 AB 587 利用規約報告書 — ソーシャルメディア企業が、自社の規約でコンテンツのカテゴリをどのように定義し執行するかについて、カリフォルニア州司法長官へ半期ごとに提出する書類です。各提出をリンクしたカタログ。

カタログを見る

インドIT規則

インドの2021年IT規則に基づく月次遵守報告書 — プロアクティブに対処されたコンテンツ、ユーザー苦情、対処されたアカウント、法執行機関からの要請。Facebook、Instagram、Twitter/X、Moj、ShareChat、Roblox、Google、Pinterest より。

データを探索

韓国

韓国のネットワーク関連法に基づく Naver と Kakao の半期透明性レポート — 法的要請種別ごとの政府によるユーザーデータ要請。2012年以降。

データを探索

台湾詐欺対策

台湾の詐欺防止法に基づく執行データ — 第42条により DNS ブロックされた詐欺サイト。月・サイトカテゴリ別、国家警察庁の公開登録簿より。

データを探索

トルコ 5651号法

プラットフォームがトルコの法律第5651号に基づき公表する半期ごとのコンテンツ削除レポート。個人および当局からの要請を要請元別に、Meta の Facebook・Instagram レポートと X のレポートから。

データを探索

シンガポール

指定された6サービスがシンガポールのオンライン安全行動規範に基づき提出する年次オンライン安全レポートと、IMDA のサービス横断ベンチマーク（対応率と対応時間）、および各サービスのシンガポールにおける危害カテゴリ別の数値。

データを探索

日本 情プラ法

日本の情報流通プラットフォーム対処法（情プラ法）の実施状況統計 — LY コーポレーションのメディア透明性レポート。Yahoo!知恵袋、LINE オープンチャット、VOOM ほかの投稿件数・削除件数・削除割合。

データを探索

Meta — 執行状況

Meta の自主的なコミュニティ規定施行レポート。Facebook・Instagram における蔓延度、措置したコンテンツ、事前対応率、異議申し立てを、ポリシー領域別に、2017年以降四半期ごとに掲載。

トレンドを探索

TikTok — 執行状況

TikTok の自主的なコミュニティガイドライン施行レポート。削除した動画・アカウント・コメント、事前対応率と削除の速さを、ポリシー・モデレーション方式別に、2020年以降四半期ごとに掲載。

トレンドを探索

Google — 削除

Google の各種プロダクトにおける政府からのコンテンツ削除要請 — 178 か国、30 の報告期間、複数年にわたるトレンドエクスプローラー。

トレンドを探索

Google — ユーザーデータ

Google が報告した政府によるユーザー情報要請 — 国・法的手続別の要請件数、アカウント数、開示率に加え、外交ルート、Enterprise Cloud、米国国家安全保障のレンジ値。2009年から半期ごと。

データを探索

Apple

Apple が報告する、デバイス・アカウント・金融識別子などのデータに関する政府および私人からの要請と、App Store での削除を、期間・国・要請種別ごとにまとめたもの（2013 年上半期以降）。

データを探索

Snap

Snap が報告する、トラスト＆セーフティの執行、政府によるコンテンツ・アカウント削除および情報の要請（米国の国家安全保障を含む）、DMCA・商標通知を、セクション・カテゴリ・指標ごとに。

データを探索

GitHub

GitHub が報告する、政府による削除、ユーザー情報の開示要請（国家安全保障レターを含む）、DMCA 通知、自動検出、異議申し立て、EU DSA の月間アクティブユーザー。

データを探索

Microsoft

Microsoft の Law Enforcement Requests Report — 国別の顧客データに対する法的要請とその開示結果（コンテンツ、非コンテンツ、データなし、却下）。2013年から半期ごと。

データを探索

LinkedIn

LinkedIn の Government Requests Report — 国別のメンバーデータ要請、レンジ値の国家安全保障数値を含む米国の法的手続内訳、政府によるコンテンツ削除要請。

データを探索

TikTok

TikTok の政府・法的要請レポート：国別の政府によるコンテンツ削除要請とユーザー情報要請、および知的財産／著作権に基づく削除要請。2019 年以降、半期ごと。

データを探索

Discord

Discord の透明性レポート：ポリシーカテゴリ別の信頼と安全の措置（対応したアカウント・サーバー・メンバー）と、国別の政府・法的要請。2022 年以降、四半期ごと。

データを探索

Google — 障害

Google のトラフィックと障害のカタログ：政府命令によるインターネット遮断・ブロック・停止のうち Google 製品に影響したもの。報道ソースの出典付き、2009 – 2021 年。

データを探索

Google — Android

Google の Android エコシステム セキュリティ レポート：デバイスおよび Google Play における有害な可能性のあるアプリ（PHA）の割合。Android バージョン・国・マルウェアのカテゴリ別、2017 – 2024 年。
